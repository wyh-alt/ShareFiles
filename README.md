# ShareFiles

局域网文件分享工具。拖入文件即可生成下载链接，并实时显示当前下载状态，便于在确认无人
下载后再关闭程序。

HTTP 服务基于 Python 标准库 `http.server`（即 `python -m http.server` 所使用的
`ThreadingHTTPServer` + `SimpleHTTPRequestHandler`），服务端无第三方依赖。

## 快速开始

```bash
pip install PyQt6 PyQt6-Fluent-Widgets    # 仅界面需要，服务端不需要
python app.py
```

程序启动后即开始共享，只需两步：

1. **拖入文件或文件夹** —— 文件夹将作为可浏览的目录共享
2. **点行尾的复制图标** 取走这一项的链接，发给对方

分享列表底部有三个按钮：**复制链接**（复制共享根地址，打开后能看到全部内容）、
**刷新链接**、**清空列表**。

## 随机分享地址

每次启动程序都会随机生成一串 16 位的地址前缀，所有链接都长这样：

```
http://192.168.1.5:8000/bc2e61f229146a11/报告.pdf
                      └────── 随机前缀 ──────┘
```

**光知道 IP 和端口是进不来的**——直接访问 `http://192.168.1.5:8000/` 只会得到一个 404，
必须带上完整的前缀才能看到内容。所以曾经用过这个地址的人、或者在同一网段扫端口的人，
都不会再误入你的分享。

前缀用密码学安全的随机源生成（64 位熵），猜不出来。点「刷新链接」可以随时换一串新的，
旧链接**立即失效**；换的时候如果正有人在下载，程序会先提示——已经开始的下载不会中断，
但对方万一断线就没法用旧链接续传了。

「分享内容」和「下载详情」每个列表一屏最多显示 8 行，超出后在列表内部滚动。新加进来的
内容排在末尾，界面会自动滚过去，不用自己往下拖。文件名过长时从中间省略（保留扩展名），
鼠标悬停可以看到完整名称和所在路径。

窗口底部状态栏持续显示当前状态（把鼠标停在「当前处于共享中」上可以看到访问地址）：

```
● 当前处于共享中   ● 当前 1 个下载队列（2 条连接）
```

## 同一台电脑只跑一个

第二次启动会提示"程序已在运行"，并且**顺手把已经开着的那个窗口叫到前面来**（程序收在
托盘里时，这一下正好派上用场）。程序退出后管道自动释放，下次照常能启动。

之所以要限制，是因为两个实例会抢同一个端口——真让它们都起来，反而会出现"链接时好时坏"
这种最难查的问题。

## 关闭窗口时

首次点关闭会问一句：**收进托盘**还是**退出程序**，可以勾「记住我的选择，以后不再询问」。
也可以直接在**高级设置 → 桌面**里先把「关闭时隐藏窗口收进托盘」定下来，那样就不会再问了。

- **收进托盘** —— 共享继续运行、链接保持有效；双击托盘图标回到窗口，右键菜单里有「退出」
- **退出程序** —— 停止共享、链接随即失效；如果这时有人在下载，会先提示确认

关窗口、或从托盘与悬浮球的右键菜单选「退出」时，若分享列表里还有内容，都会先弹窗问一句要不要
停止共享。唯一的例外是**首次**关闭：那个「收进托盘还是退出」的询问框本身已经交代过链接会失效，
紧接着就不重复问了；关闭行为早已定下时（这次没弹询问框），该问的一句不会少。

窗口正常显示时用的是应用内的对话框；**窗口收在托盘里或最小化时改用系统对话框** ——
前者是盖在窗口上的一层遮罩，窗口看不见时它也跟着看不见，用户会以为程序卡死，
实则是对话框在那儿等着点击。窗口最小化时 `isVisible()` 仍为真，判断"窗口此刻可不可用"
要连最小化一起看（见 `MainWindow.window_usable`）。

### 桌面悬浮球

窗口收进托盘或最小化之后，桌面边缘会出现悬浮球（程序图标做成的一颗圆球，带点反光）：

| 操作 | 效果 |
|---|---|
| 鼠标移上去 | 球亮一档，旁边浮出当前分享概况：「3 个分享文件 · 7 次下载记录」，没有分享则是「当前没有分享文件」 |
| 拖文件 / 文件夹到球上 | 球再亮一档、边缘透出一圈光，浮出的提示换成「拖到此处松手即可分享」；松手即加入分享列表 |
| 拖动悬浮球 | 停在哪儿都行，松手后**滑**到最近的一条屏幕边缘（上下左右四条边都算） |
| 双击 | 把主窗口叫回来（球随即让开）；单击不做事，避免在桌面边上随手点到 |
| 右键 | 打开主窗口 / 隐藏悬浮球 / 退出（分享列表非空时会先问一句） |

光标平时就是普通箭头 —— 它更像个桌面摆件，不是个按钮；按住拖动时才换成抓取手型。

没人搭理的时候，球会在 0.1 秒后淡到半透明，不再挡着后面的内容；鼠标一碰、或者拖着文件靠近，
它立刻恢复清晰。要彻底收掉它，在球上点右键选「隐藏悬浮球」，之后想找回来得去
**高级设置 → 桌面**里勾。

有人下载时，球里侧会绕出一圈绿色进度环（十二点方向起，顺时针），不开窗口也看得出进展；
多个任务一起下时按字节数合计成一个总进度，细账在窗口里的下载详情。没有下载就收起来。

球停的位置会记进配置文件，下次显示时沿用。换了显示器、改了分辨率，
原来的坐标若已经不在屏幕里，会自动贴回可见的边缘。

球只在窗口不可用的时候露脸（收进托盘或最小化）—— 窗口开着时界面上本来就有拖放区，
不必再多一颗球挡着桌面；窗口一恢复，球就收起来。

### 下载提醒

有人**开始下载**、**下载完成**、**下载中断**这三种情况都会说一声，形式看窗口状态：

| 窗口状态 | 提醒方式 |
|---|---|
| 正常显示 | 窗口右上角的通知条 |
| 最小化 / 收进托盘 | Windows 系统通知，同时在悬浮球旁展开一条临时条幅（5 秒后自动淡出） |

条幅带一个状态色点：蓝色开始下载、绿色下载完成、黄色下载中断。下载记录只在界面上滚动显示，
追不上的话事后可以在「下载详情」里查，也能导出成表。

球旁这条条幅三种内容共用，同一时刻只显示一条，优先级是：拖放中的操作提示 > 下载通知 >
鼠标悬停时的分享概况。通知淡出后，鼠标若还停在球上，概况会接着显示。

程序收进托盘后，托盘图标的右下角会点一个小圆点表示当前状态：

| 圆点 | 含义 |
|---|---|
| ⚪ 亮色 | 正在共享，当前无人下载 |
| 🟢 绿色 | 有人正在下载 |

鼠标停在托盘图标上也有同样的文字提示，不用打开窗口就能知道有没有人在下。

没有托盘的少数环境下不会问，直接走退出。

## 下载详情

界面下方列出每一次下载，含**下载者 IP**，进行中的排在上面、已结束的作为记录留在下面：

```
🟡 192.168.1.8   幻梦5.0韩语版加字幕.mp4   ▓▓░░░░  15%      1.8 MB/s
🔴 192.168.1.9   完稿母带.mp4              ▓░░░░░  已中断   1.2MB/8.6MB
🟢 192.168.1.7   预算表.xlsx               ▓▓▓▓▓▓  已完成   175.8KB
```

每条前面是一个颜色点，一眼就能扫出状态：

| 颜色 | 状态 | 显示 |
|---|---|---|
| 🟡 黄 | 下载中 | 实时进度与速度 |
| 🟢 绿 | 已完成 | 文件大小 |
| 🔴 红 | 已中断 | 进度条停在中断的位置，显示已传 / 总大小 |

窗口宽度有限，放不下的信息（精确时间、连接数、完整文件名）都在悬停提示里。记录按任务
开始的时间排列，最新的在最下面；一条任务从「进行中」变成「已完成」时位置不会动。

记录会一直留到最后一次下载结束后仍在界面上，方便事后确认"到底是谁下走了什么"。
点「清空记录」可移除已结束的那些，进行中的不受影响。

点「导出记录」可以把这次运行期间的下载都存成一张 CSV 表（带 BOM，Excel 双击打开中文不乱码），
表头是：开始时间、最后活动、下载者 IP、文件名、文件大小、已传输、耗时(秒)、平均速率、峰值速率、
状态、峰值连接数。进行中的任务也会一并写进去。

平均速率按「已传字节 ÷ 耗时」算，峰值速率取下载过程中出现过的最高速度（与界面上显示的速度
同源，都做了指数平滑）。局域网里的小文件常常在 `time.time()` 的精度（约 15 毫秒）之内就传完，
这种耗时记为 0 的记录，两项速率都留空，而不是填一个不可靠的数字。

时间写成 ISO 8601 的 `2026-10-16T11:21:41`：Excel 会把「年-月-日 时:分:秒」那种空格写法识别成
日期，列宽不够时整列显示成 `#`；带 `T` 的写法它按文本处理，内容完整可见。

「峰值连接数」是一次下载中出现过的最大并发连接数：浏览器下载通常是 1，下载工具分段拉会更高。
记峰值而不是结束时的值 —— 任务一结束实时连接数就归零，那一刻的数字没有意义。

状态是按「下载者 + 文件」聚合的，所以用下载工具分八段拉一个文件只算一条，中途断线
重连续传也仍然归在同一条上——不会因为断了一次就多出一条记录。

## 高级设置

右上角「高级设置」包含三组选项。

**网络** —— 局域网地址、端口、是否允许浏览器预览，以及是否允许浏览器直接打开文件。
地址或端口变更后会重新监听（若存在进行中的下载会先提示确认）；端口被占用时自动顺延。

**桌面** —— 两项：

| 选项 | 行为 |
|---|---|
| 关闭时隐藏窗口收进托盘 | 勾选：点关闭只是把窗口收进托盘，共享继续、链接保持有效；不勾选：关闭即退出程序。定下来之后关窗口就不再询问 |
| 窗口隐藏后显示悬浮球 | 窗口收进托盘或最小化时，在桌面留那颗球。取消勾选等于把球收起来（也可以直接在球上点右键选「隐藏悬浮球」，效果一样）；勾上的当下只要窗口不可用，球会立刻出现 |

这两项与关窗口时的询问框写的是同一个配置值：首次关闭会先问一次（可勾选记住），
之后无论在哪儿改，都以最后一次为准。

**下载安全** —— 两项默认均未启用，持有链接的用户可直接下载：

| 选项 | 行为 |
|---|---|
| 需要密码才能下载 | 访问时浏览器要求身份验证，**用户名可任意填写或留空，仅校验密码** |
| 限制下载次数 | 每个分享项独立计数，界面上显示「剩 N 次」 |

下载次数按「完整下载一次」计算：中途断线重试、下载工具分段请求均只计一次。额度用尽后
该链接返回 403。

> 密码采用 HTTP 明文校验（Basic Auth），可阻止未获授权的访问，但无法防御网络抓包。
> 局域网环境下通常足够；如需防御嗅探则需启用 HTTPS，这要求配置证书，且接收方浏览器
> 会先提示证书不受信任。

随机前缀和访问密码是两回事，可以叠加使用：

| | 挡得住 | 挡不住 |
|---|---|---|
| 随机前缀 | 知道 IP 但没拿到链接的人、扫端口的、以前用过这地址的人 | 链接被转发出去 |
| 访问密码 | 拿到链接但不知道密码的人 | 网络抓包（Basic Auth 是明文校验） |
| IP 黑名单 | 指定的设备，连链接都不必给 | 对方换了 IP |

三者都**不加密传输内容**，只控制"谁能访问"。要防嗅探得上 HTTPS。

### IP 黑名单

同一张「高级设置」里可以维护一个 IP 黑名单：列表里加进去的 IP 访问任何分享链接都会收到
403，索引页和打包下载一并拦下。

- 支持**单个 IP**（`192.168.1.100`），也支持**整个网段**（`192.168.1.0/24`）
- 底下输入框填好点「添加」；选中条目点「移除」；**双击列表项可直接改**
- 格式不对的条目会被拒绝（添加时提示；双击改坏了则在保存时跳过并告诉你跳了几条）
- 改完点保存即生效，不需要重开共享

黑名单检查和随机前缀、密码是分开的三道关，顺序是**先查黑名单**——被拉黑的连密码框
都不会看到。

## 使用说明

### 链接形式

每个分享项对应一条链接，复制到剪贴板的是百分号编码形式（聊天工具、浏览器、命令行都能
稳妥处理）。`<前缀>` 就是上面那串随机地址：

```
http://192.168.1.5:8000/<前缀>/报告.pdf        文件
http://192.168.1.5:8000/<前缀>/照片/            文件夹，打开为目录列表
http://192.168.1.5:8000/<前缀>/                 索引页，列出全部共享内容
```

### 局域网地址

地址由程序**自动检测**，「高级设置」里只做展示，不提供选择——默认取系统实际用于联网的
那块网卡。本机有多个网卡时，把鼠标停在地址上可以看到检测到的全部地址。

换网络环境后（比如从公司带回家），配置里存的旧地址若已不属于本机任何网卡，启动时会自动
改用当前网卡，不会拿着一串失效地址去生成链接。

### 下载全部（打包）

对方打开索引页或某个文件夹时，右上角有个「下载全部」，点一下就把当前这些内容打成一个
zip 传过去，不用一个一个点。文件夹的层级会原样保留在包里。

打包的几点行为：

- **已经压过的格式不再压第二遍**（mp4、jpg、zip、pdf 这些），用了就跳过 deflate，
  免得白烧 CPU 还几乎压不动
- **打包过程同样计入下载详情**，发起者能看到"谁在打包下载什么、进度多少"
- **会消耗次数额度**：包里包含的每个分享项各记一次下载。额度用完的那些直接排除在包外
  —— 不然点一下「下载全部」就等于把每个文件的额度白送一次

内容多的时候打包要花点时间，这段时间页面没有进度提示，等浏览器开始下载就说明包好了。

### 下载方式与预览

默认启用强制下载（`Content-Disposition: attachment`），点击链接即保存文件，不会在浏览器
中打开。如需在浏览器中直接查看图片或播放视频，请在高级设置中勾选「允许浏览器直接预览」。

### 断点续传

服务端支持 HTTP Range，下载中断后可续传，视频可拖动进度条。服务停止后重新启动，接收方
使用下载工具仍可继续下载，无需重新开始。

### 接收方无法连接

首次共享时 Windows 会提示防火墙授权，需选择「允许访问」。若当时选择了取消，可在
「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」中允许 Python 通过。

## 配置文件

首次运行会在用户目录下自动建出 `~/.sharefiles/config.json`（Windows 上是
`C:\Users\<用户名>\.sharefiles\config.json`），把「高级设置」里的东西存下来：

```json
{
  "version": 1,
  "ip": "192.168.1.5",
  "port": 8000,
  "preview": false,
  "password": "",
  "limit": 0,
  "blocked": ["192.168.1.0/24"],
  "close_action": "",
  "ball_x": null,
  "ball_y": null,
  "ball_enabled": true
}
```

`close_action` 记的是关窗口时的选择（`"tray"` / `"quit"`），空着就每次询问。

`ball_x` / `ball_y` 是桌面上那颗悬浮球的停靠位置，没手动拖过就是 `null`（默认停在屏幕右边
居中）。坐标若已不在任何一块屏幕里（拔了显示器、改了分辨率），下次显示时会自己贴回可见边缘。
`ball_enabled` 是悬浮球的总开关，在球上右键选「隐藏悬浮球」会把它置为 `false`。

每次点「保存」写回，下次启动读出来，不用重新配一遍。

几个容错设计：

- **文件被删了、手改坏了、字段类型不对** —— 一律退回默认值继续跑，不会因为一个配置文件
  让程序起不来；端口越界会被夹回合法范围
- **换了网络环境** —— 配置里存的地址如果已不属于本机任何网卡（比如从公司带回家），
  启动时会自动改用当前网卡，不会拿着一串失效的地址生成链接
- **写入是原子的** —— 先写临时文件再替换，避免写一半断电留下个坏文件

> 密码是**明文存在这个文件里**的。它只放在你的用户目录下，但同时也要知道：这个密码本身
> 走的就是 HTTP 明文校验，文件里的明文并不比传输环节更弱。如果不想留，把 `password`
> 改成空字符串即可。

`fileserver.py` 不依赖界面，可直接以命令行方式共享：

```bash
python fileserver.py "D:/报告.pdf" "E:/照片" -p 8000
```

## 实现说明

- **虚拟挂载点**：标准库的 `SimpleHTTPRequestHandler` 仅支持单一根目录，此处重写了
  `translate_path()`，使位于不同盘符的文件各自映射为独立 URL。路径穿越设置了两道防护
  （拒绝 `..` 路径段 + `realpath` 前缀校验）。
- **下载按任务而不是按连接记账**：追踪器记录的是「某来源下某文件」这件任务，而不是
  HTTP 连接。任务状态由「当前还有没有活跃连接」推出：有连接即进行中，连接没了且已传够
  整个文件即完成，否则算中断；之后重连续传又会自动回到进行中。这样多线程下载只出一条
  记录、断线重连不会多出记录，都不需要单独的状态机。
- **页面底色由应用自行绘制**：`AcrylicWindow` 的云母效果在远程桌面及部分显卡驱动环境下
  不生效，未绘制区域会呈现深色，浅色主题下尤为明显。因此页面、状态栏底色均随主题自行设置。
- **悬浮球是一块透明窗口**：无边框、置顶、不接收焦点，球面（径向渐变 + 顶上一点高光）
  全由 `QPainter` 画出来；鼠标悬停、文件拖过来时只是把亮度提上去，球本身不改变大小。
  它刻意不挂在主窗口名下 —— 挂上去的话，主窗口一 `hide()` 它也会跟着被藏起来。
- **闲置变淡用的是绘制透明度，不是 `setWindowOpacity`**：后者在这种自带 alpha 的
  无边框窗口上落不到实处 —— Qt 只在它自己那边记个数，既不设置分层窗口属性，窗口内容
  的像素也纹丝不动（`PrintWindow` 抓出来对比过）。所以淡的是 `QPainter` 那几笔，
  和球边的抗锯齿走同一条 alpha 路子。
- **球的形状交给窗口区域，不指望透明合成**：透明区域得靠系统合成才真的透明，
  合成稍有不配合，球外面那圈就成了白底，看着是个方块。所以窗口本身用
  `setMask()` 裁成圆形，再用 `DwmSetWindowAttribute` 关掉 Win11 给顶层窗口
  配的边框、圆角与背景——两边都堵上，球才是一颗干净的球。
- **Windows 下禁用 `SO_REUSEADDR`**：Windows 允许两个进程绑定同一端口，内核将连接随机
  分配给其中之一。若前一实例未完全退出即再次启动，会表现为链接访问时好时坏、间歇性 404。
  故选择让绑定失败并顺延端口。
- **使用系统原生标题栏**：qfluentwidgets 的无边框窗口在部分环境下无法绘制云母效果，自绘
  标题栏的按钮图标会与背景混淆。系统标题栏的按钮由系统绘制，可正确跟随深色/浅色主题。
- **下载次数按整个文件计数**：若按单次传输计数，下载工具分段请求一次即会消耗多个额度。
  因此累计同一来源对同一文件的传输字节数，达到完整文件大小方计为一次。
